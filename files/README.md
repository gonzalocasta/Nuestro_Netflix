# Directorio de Imágenes

Este directorio está destinado para almacenar las carátulas de las películas localmente.

## Uso

Puedes colocar imágenes de películas en este directorio y referenciarlas en la aplicación usando rutas relativas:

```
files/mi_pelicula.jpg
```

## Formatos Recomendados

- JPG/JPEG
- PNG
- WebP

## Nota

La aplicación actualmente utiliza URLs de imágenes en línea de Unsplash como ejemplo, pero puedes reemplazarlas con rutas locales a este directorio.
